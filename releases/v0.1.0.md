# xk6-llm v0.1.0

First release. LLM-aware load testing for k6 against any OpenAI-compatible chat-completions server.

## Features

- `llm.Client`: streaming chat client with TTFT/ITL/TPOT measurement, categorized error tagging, custom HTTP headers.
- `llm.Dataset`: JSONL prompt corpus replay with deterministic seeded shuffle. Includes `scripts/sharegpt_to_jsonl.py` for ShareGPT V3 conversion.
- Goodput and per-SLO Rate metrics matching `vllm bench serve --goodput` semantics.
- Optional `cost` and `energy` per-request estimation.
- Quickstart Docker Compose stack with Prometheus + Grafana and a pre-provisioned dashboard.

## Validation

Cross-validated against `vllm bench serve` on a real vLLM 0.21.0 server (Qwen2.5-72B-Instruct-AWQ, A100 80GB). TPOT/ITL/E2EL agree within 5% on identical workloads; token counts are bit-exact with vLLM `/metrics`. See [`docs/validation-parity.md`](../docs/validation-parity.md) and [`docs/validation-results.md`](../docs/validation-results.md).

## Compatibility

- k6 `v2.0.0`, xk6 `v1.4.1`, Go `1.25.x`.
- Servers verified: vLLM, Ollama, llama.cpp server.
