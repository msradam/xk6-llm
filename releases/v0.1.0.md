# xk6-llm v0.1.0

First public release. LLM-aware load testing for k6 against any OpenAI-compatible chat-completions server.

## Metrics

| Name | Type | Notes |
|---|---|---|
| `llm_requests` | Counter | Successful completions. |
| `llm_errors` | Counter | Tagged `error_type` in `{network, timeout, http_4xx, http_5xx, stream, decode}`. |
| `llm_request_duration` | Trend (Time) | End-to-end. |
| `llm_response_headers` | Trend (Time) | Submit to HTTP headers received. |
| `llm_ttft` | Trend (Time) | First content-bearing SSE chunk; role-only deltas skipped. |
| `llm_itl` | Trend (Time) | Per-chunk inter-arrival vector; first sample is `chunk₂ - chunk₁`. |
| `llm_tpot` | Trend (Time) | Scalar `(e2e - ttft) / (n - 1)`. Emitted only when `n > 1`. |
| `llm_chunks_per_request` | Trend (Default) | Multi-token chunks detectable when `chunks < completion_tokens`. |
| `llm_prompt_tokens`, `llm_completion_tokens` | Counter | From server `usage` block when emitted. |
| `llm_goodput` | Rate | All SLOs met. Emitted only when an `slo` predicate is supplied. |
| `llm_slo_ttft`, `llm_slo_tpot`, `llm_slo_e2el` | Rate | Per-SLO attainment for diagnosis. |

## API

```js
import llm from 'k6/x/llm';

const client = new llm.Client({
  base_url: 'http://localhost:11434/v1',
  api_key:  '',
  model:    'granite4.1:3b',
  timeout_ms: 60000,
  slo: { ttft_ms: 500, tpot_ms: 50, e2el_ms: 5000 },  // optional default
});

const res = await client.chat({
  messages:    [{ role: 'user', content: 'hi' }],
  max_tokens:  64,
  temperature: 0,
  slo:         { ttft_ms: 1000 },        // optional per-call override
  cache_state: 'cold',                   // optional, propagated as tag
  tags:        { region: 'us-east' },    // optional, propagated as tags
});
```

## Compatibility

- k6 `v2.0.0`, xk6 `v1.4.1`, Go `1.25.x`.
- OpenAI-compatible servers verified locally: vLLM, Ollama, llama.cpp server.
